Getting around Bali on **Trans Metro Dewata**, the island's public bus
network, can feel unfamiliar if you do not already know the corridors and
stops. Built in collaboration with **Forum Diskusi Transportasi Bali**,
Jelaja pairs bus navigation with landmark collecting so riding public transit
turns into exploring the island.

## How it's built

Built natively for iOS using **SwiftUI**, **CoreLocation**, and **MapKit**.

<CraftList>
  <CraftItem title="Smooth live navigation">Tuned CoreLocation updates and MapKit routing so transit guidance stays responsive while moving on the bus.</CraftItem>
  <CraftItem title="Rewarding landmark claims">Designed the location check and video capture flow so claiming a landmark feels immediate and satisfying when passing a stop.</CraftItem>
</CraftList>
