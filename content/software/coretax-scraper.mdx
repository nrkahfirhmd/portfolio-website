The tax team's data lives in Coretax, and getting it out was slow: the
records sit in a paged table, and each page could only be downloaded on its
own, by hand. Coretax Scraper is a Chrome extension that does that
extraction for them, built during my internship.

## What it does

<Points>
  <Point title="Before">Someone on the tax team opened each page of the table and downloaded it, one page at a time.</Point>
  <Point title="After">The extension pulls the data across the pages in one go, inside the Coretax page they already have open.</Point>
  <Point title="The result">A task that took about ten minutes now takes under fifteen seconds.</Point>
</Points>

## How it's built

A Chrome extension written in JavaScript. It runs in the browser alongside
Coretax, so it works with the same session the team already uses.
