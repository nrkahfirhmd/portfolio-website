The tax team's data lives in Coretax, and getting it out was slow: the
records sit in a paged table, and each page could only be downloaded on its
own, by hand. Coretax Scraper is a Chrome extension that does that
extraction for them, built during my internship. It's now part of how the
team works every month.

## How it's built

A Chrome extension written in JavaScript. It runs in the browser alongside
Coretax, so it works with the same session the team already uses. It reads
the table straight from the page and clicks through the table's pages by
itself, collecting every row on the way.

## My role

I built it on my own from October to December 2025, as the automation
engineer and data analyst on the project. It started as a tool for one task
and became part of the team's routine: the data it collects feeds their
reconciliation, the monthly report, and the PPh recap.
