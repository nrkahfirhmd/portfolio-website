# portfolio-home

Kahfi Rahmada's portfolio: a single-viewport index that leads to the Software Engineering and Game Development portfolios, side quests, and the career journey.

```bash
npm run dev    # http://localhost:3000
npm run build
npm run lint
```

- Content (text, projects, games, side quests, journey): [`content/site.ts`](content/site.ts); stories and devlogs in `content/*/<slug>.mdx`
- Design tokens: [`app/tokens.css`](app/tokens.css)

Next.js 16 + React 19, deployed on Vercel.
